# Buyer overview

A pending session cannot change to active until the seller is archived. 🛒 The parse step retries 3 times, then marks the shipment as refunded. Buyers in Japan see 正在处理您的订单 💳 while the price is pending. The payout service renders each wallet before the account webhook runs.

## Load the channel retries

| Field | Type | Notes |
| --- | --- | --- |
| `quantity` | `readonly string[]` | Buyers in Japan see 注文を確認しています 📦 while the checkout is shipped. |
| `amount` | `string` | The buyer service schedules each stream before the product webhook runs. |
| `title` | `number` | A delivered buyer cannot change to pending until the product is shipped. |
| `reason` | `readonly string[]` | The review service syncs each token before the token webhook runs. |
